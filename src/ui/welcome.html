What it will do

  • When you close the browser, local session data for high-risk sites is cleared on a best-effort basis. If the prior run did not finish, cleanup is retried after the next launch and matching restored tabs are reloaded.
  • After 30 minutes idle, or when your screen locks, the same local cleanup is triggered.
  • The extension attempts the site's own logout before clearing local data. A clicked control is reported as sign-out attempted, not proof that a copied token died. Verified revoke recipe is reserved for separately tested behavior.

Lower-risk sites are left alone by default. You can change any of this in settings.

    Important limits

    Deleting cookies removes local session material from this browser. It does not invalidate a token that was already stolen and is being used elsewhere. Only the website can invalidate that token, and a logout click alone does not prove it happened.

    Local cleanup can sign you out at an awkward moment. Use Never clear this site on anything where that would hurt.

    Clearing a site does not prove its server session ended. Session Sentinel attempts the site's sign-out first, then deletes local data. Unless a revoke-everywhere result was separately verified, review the site's active-session list yourself during an account compromise.
